# Arthur Chibondo Media

Personal brand website for Arthur Chibondo — Malawian entrepreneur, digital creator, and builder.

**Live:** https://arthur-chibondo-media.vercel.app

## Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Supabase** (database, auth, RLS)
- **Framer Motion** (animations)
- **Vercel** (deployment)

## Setup

1. Clone the repo
2. Copy `.env.local.example` to `.env.local` and fill in your Supabase keys
3. Run the SQL in `supabase/schema.sql` in your Supabase SQL editor
4. `npm install && npm run dev`
